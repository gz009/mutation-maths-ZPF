# Bookshelf inventory — the 31 books this project reads from

**These books are not in this repository and never will be.** They are
third-party, copyrighted, and they live on local disk only. This file exists so
that someone who owns the same editions can confirm they are holding the same
files the dossiers were written against.

Expected location once you have them:

```
Partition_Function_Study/Z_Ref_Books/<numbered topic folder>/
Partition_Function_Study/Maths_Proof_Skill/<numbered folder>/
```

`.gitignore` ignores both directories by name, and `make check-no-books` fails if
a book is ever staged. Drop your own copies into those paths and git will ignore
them exactly as it does here.

Which book to read, which section, and in what order is in
[`Z_Ref_Books__MANIFEST.md`](Z_Ref_Books__MANIFEST.md) and
[`Maths_Proof_Skill__MANIFEST.md`](Maths_Proof_Skill__MANIFEST.md).

Checksums taken 19 September 2026. MD5 is used for file identity here, not security.
